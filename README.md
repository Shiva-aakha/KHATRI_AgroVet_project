# KHATRI_AgroVet_project
KHATRI AgroVet Center — Retail Inventory &amp; POS Web Application (agrovet_center.html)  A lightweight, single-file retail management, point-of-sale (POS), and farmer credit ledger web application tailored for KHATRI AgroVet Center in Bheriganga-9, Jahare Bazzar, Surkhet, designed around a NPR 5 Lakh (NPR 5,00,000) working-capital operation.
